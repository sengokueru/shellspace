# IR（インパルスレスポンス）— Cubase REVerence / ドラム用

DAWのコンボリューションリバーブに読み込むwav。**wavは生成物**（gitでは追跡しない）。
`make_ir.py` が原本で、いつでも作り直せる。

```bash
py -3 IR/make_ir.py IR        # 生成
py -3 IR/verify_ir.py IR      # 実測検証（RT60・ピーク・モード・ch順）
```

全ファイル 48kHz / 24bit / ピーク -1.0dBFS。

> **ホールIRに直接音は入っていない。** センド（FXトラック）に挿してMix 100%で使う前提。
> インサートで使う場合はプラグイン側のMixで混ぜる。

## ファイル

| ファイル | ch | 長さ | 用途 |
|---|---|---|---|
| `Hall_Yokosuka-type_Full_TrueStereo.wav` | 4 | 2.90s | **本命。** ホール本来の低域。REVerenceが自動でTrue Stereo動作 |
| `Hall_Yokosuka-type_Full_Stereo.wav` | 2 | 2.90s | モノ素材用・CPU節約用 |
| `Hall_Yokosuka-type_Drum_TrueStereo.wav` | 4 | 2.90s | **ドラム用。** 低域を締めて溜まりを防いだ版 |
| `Hall_Yokosuka-type_Drum_Stereo.wav` | 2 | 2.90s | 同上・2ch |
| `Shell_<Kind>_<Material>_<Kit>.wav` | 2 | 0.75〜1.30s | 3種×4胴材×4キット＝48本 |
| `Cab_Guitar_4x12.wav` | 2 | 85ms | 12インチ4発の合成ギターキャビ |
| `Cab_Bass_8x10.wav` | 2 | 85ms | 密閉10インチ8発の合成ベースキャビ |

4chファイルは **LL, LR, RL, RR** の順（REVerenceが要求する唯一の並び）。
ステレオトラックに挿して4ch IRを読むと自動でTrue Stereoになる。

## ホール

横須賀芸術劇場・大ホールのような「馬蹄形で客席幅が狭く、天井が高い」オペラハウス型の合成IR。
**現地実測ではない**（その形の部屋がどう鳴るかを設計して合成したもの）。

「上に長い」を成立させている3要素:

| 要素 | 設計 | 効果 |
|---|---|---|
| 側壁初期反射 | 11.5 / 14.2ms | 幅が狭いので早く返る＝密度が出て近く聞こえる |
| バルコニー4層 | 19〜92ms に段状 | 馬蹄形の階層が刻む中期の粒 |
| **天井1次反射** | **118 / 131 / 146ms** | 高い天井のせいでER群が終わった後に単独で来る。**これが縦方向の広さの正体** |

### 実測RT60（T20法・オクターブバンド・秒）

| 版 | 63-125 | 125-250 | 250-500 | 500-1k | 1k-2k | 2k-4k | 4k-8k | 8k-16k |
|---|---|---|---|---|---|---|---|---|
| **Full** | 1.71 | 1.58 | 1.72 | 1.84 | 1.82 | 1.58 | 1.23 | 0.82 |
| **Drum** | 1.44 | 1.40 | 1.64 | 1.84 | 1.85 | 1.61 | 1.23 | 0.82 |

Drum版は中域を保ったまま低域だけ約0.4秒短い。キックが溜まらない。

### True Stereo の実測（0-160msのエネルギー）

`LL=+23.3 / LR=+17.9 / RL=+18.5 / RR=+23.2 dB` — **同側が5.4dB優位、左右対称は0.6dB以内**。
左の音は左から、右の音は右から返る。定位が滲まない。

## REVerence の設定

**読み込み** — プラグイン右下の `Import` → wavを選択 → プログラム枠に登録。

| パラメータ | 推奨 | 理由 |
|---|---|---|
| **ER Tail Split** | **160 ms** | ここが最重要。**天井1次反射(118/131/146ms)をER側に含める境界**。100msなどにすると天井がテール扱いになって「上への広さ」が消える |
| ER Tail Mix | 50（基準） | 50超でER減衰、50未満でテール減衰。**天井を強調したいなら45付近**でテールを下げる |
| Predelay | 0〜30 ms | 0でも最初の反射が9〜11msにあるので自然。生ドラムはアタックを守るため **20〜30ms** |
| Size | 100% | 変えると時間軸ごと伸縮する（＝ピッチも動く）。ホールでは基本触らない |
| Auto Gain | ON | 版を差し替えても音量が揃う |

**生ドラム** — Drum版をFXトラックに。ドラムバスからセンド。センドの手前で **HPF 120Hz** を入れるとキックのかぶりがホールに送られなくなる。オーバーヘッドが持つ実際のルーム音と喧嘩するので、送り量は控えめ（-15dB前後）から。

**ドラム音源** — Full版でよい。素の音が乾いているので送り量は強めでも破綻しない。

## 胴鳴り（Shell_*）

**残響成分のみ**（頭に直接音なし）。L/R完全同一のデュアルモノなのでモノ互換で位相が崩れない。

ファイル名の `Material` は `Maple / Birch / Mahogany / Oak`、`Character` は
`Studio / Projection / Tight / Open`（胴の構造による鳴り方）。
胴材と構造は独立に選べるため、実在しない組合せも音作り用に生成する。

| ファイル | RT60 | 実測モード(Hz) | 特徴 |
|---|---|---|---|
| Kick | 0.64s | 36 / 49 / 62 / 78 / 96 / 132 | ピッチが落ちながら伸びる＝「ボゥン」。30HzでHPF済み |
| Snare | 0.31s | 183 / 196 / 220 / 287 / 333 / 412 | 胴＋スナッピーのざらつき(4.2k/7.5k)。70HzでHPF済み |
| Tom | 0.87s | 114 / 135 / 176 / 212 / 268 / 355 | ピッチが落ちながら伸びる。45HzでHPF済み |

### ピッチを自分のドラムに合わせる

REVerenceの **Size** がIRを時間軸ごと伸縮するので、これがピッチつまみになる。

```
合わせたい周波数 = 上表のモード周波数 × (100 / Size%)
```

例：タムの基音を135Hz→160Hzに上げたい → Size = 135/160×100 = **84%**。
Sizeを縮めると減衰も同じ比率で短くなる（実機のチューニングと同じ挙動なので都合がよい）。

### 使い方
- **センドで戻して混ぜる。** インサートで100%通すより量を制御しやすい。
- 溜まりすぎたら、IRではなく**戻りにEQ**を挿す。犯人はキック60Hz付近、タム135Hz付近。

## キャビネット（Cab_*）

最小位相の合成IR。アンプ／歪みそのものは含まず、スピーカー＋箱の周波数制限を担当する。

| IR | 生成後の実測（1kHz基準） |
|---|---|
| Guitar 4x12 | 80Hz −5.7dB / 3kHz +1.7dB / 5kHz −12.4dB / 8kHz −43.6dB |
| Bass 8x10 | 40Hz −12.9dB / 58Hz −4.7dB / 110Hz +1.1dB / 5kHz −4.7dB |

**特定製品の実測ではない。** その構成のキャビに共通する帯域特性を
周波数アンカーとして与え、最小位相で合成したもの。

## Kemper / Fractal に持っていけるか

**プリセット(.kipr / .syx)の直接生成は不可**（独自バイナリで公開仕様がない）。ただし公式ツールがwavを変換するので、問題は長さ制限のほう。

| | 取り込み方法 | 長さ上限 | 今回のIR |
|---|---|---|---|
| Fractal (Axe-Fx III / FM9 / FM3) | Axe-Edit の Cab Manager にD&D | **2048サンプル ≒ 43ms** | ❌ 全滅 |
| Kemper | 無償 **Cab Maker** で wav → .kipr | **1.5秒 (66,150 sample @44.1k)** | △ 胴鳴り3本は入る。ホール2.9sは ❌ |

両機のIR枠は**キャビネットIR用**でリバーブを入れる場所ではない。ホールを実機で鳴らすならリバーブブロックのパラメータで再現するしかない。
（Kemperに胴鳴りを入れる場合、Cab Makerが44.1kHz以外を弾く報告があるので `make_ir.py` の `SR` を44100にして書き出す）

## 作り直したいとき

`make_ir.py` の以下を触る:

| 変えたいもの | 場所 |
|---|---|
| 天井の高さ | `HALL_ER` の 118/131/146ms。**後ろにずらすほど天井が高くなる** |
| ホールの残響長 | `HALL_RT`（バンドごとの秒数）。実測T20とはズレるので必ず `verify_ir.py` で確認 |
| ドラム版の低域の締め | `jobs` の `hall_true_stereo(0.80, ...)` の第1引数。小さいほど低域が短い |
| True Stereoの左右差 | `hall_pair` 内の `side = 4.5 * src * ...` の 4.5（dB） |
| 胴鳴りのピッチ/減衰 | `SHELLS` 辞書（周波数, 音量, 減衰秒, グライド比, HP周波数） |
